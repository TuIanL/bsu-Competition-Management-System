## 4. 数据库约束（`database/test_constraints.py`）

重复学号、非法志愿者状态、需求人数为 0、开始晚于结束、不存在的外键、重复调度、重复报名、非法调度状态、非法报名状态、签退早于签到、COMPLETED 缺少时间、**时间格式不规范、日期格式不规范、不存在的日期、已完成考勤被改回**（后 4 项为 V1.3 新增）—— 15/15 被数据库拦截。

## 5. 测试中发现并修复的问题

| # | 问题 | 发现方式 | 处理 |
|---|---|---|---|
| 1 | 演示班次日期固定为 10 月，已过期，可报名列表为空（总控台 Q5） | 运行 seed 后检查 | seed 改为相对运行日期生成 |
| 2 | `CHECK (x = date(x))` 对非法日期不生效（`date()` 返回 NULL，CHECK 视为通过） | 新增约束测试失败 | 改为 `IS` 比较 |
| 3 | 志愿时长按"签退−签到"原值计算，签到后很久才签退会虚增时长 | 设计评审 | 改为裁剪到班次时间内的有效时长 |
| 4 | Windows Git Bash 下脚本打印 emoji/中文可能报编码错误 | 代码审查 | 脚本统一 `stdout.reconfigure(encoding="utf-8")` |
| 5 | `init_db.py`/`seed.py` 必须在 `database/` 目录下运行，否则在当前目录生成空库 | 代码审查 | 改为按脚本所在目录定位 |
